# Para Ali — un universo en canciones

Página interactiva dedicada a Ali, inspirada en las eras y canciones de
Ariana Grande.

La página contiene ocho álbumes, sus canciones, dedicatorias personalizadas,
animaciones, cambios de color y previas musicales mediante Spotify.

Consulta `LEEME-PARA-PUBLICAR.txt` para activar GitHub Pages.
